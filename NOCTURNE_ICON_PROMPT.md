# Nocturne App Icon Design Prompt

## Goal
Create a premium, minimal app icon for Nocturne using the design-taste-frontend skill. Make it look refined, modern, and distinctly different from generic music app icons.

## Context
- App name: Nocturne
- Vibe: iOS-style Liquid Glass music player, dark/premium aesthetic
- Platform: Android + general use
- Current icon: simple music note in gradient (needs improvement)

## Requirements
- **Style**: Minimal, geometric, premium. Think modern iOS app icons
- **Concept**: Abstract music note or sound wave that feels elegant
- **Shape**: Square with rounded corners (adaptive icon ready)
- **Colors**: Dark background (#0f0f13) with accent glow (violet/cyan/purple)
- **Details**: Subtle glow, glass-like effect, or gradient
- **Avoid**: Overly detailed, skeuomorphic, literal CD/disc, speaker grills, AI-looking blobs
- **Output**: SVG + PNG (512x512, 1024x1024, adaptive icon sizes)

## Use design-taste-frontend skill
Load the skill and follow its principles:
- Make decisions, don't use defaults
- Find unique idea from the name "Nocturne" (night music, moonlit)
- Keep it minimal and refined
- Test with real rendering

## Design Direction
Consider:
- Abstract waveform/note that curves like a crescent moon
- Single elegant stroke forming musical symbol
- Subtle glow/effect suggesting liquid glass
- Monochromatic or limited palette
- Works at small sizes (48x48)

## Deliverables
1. `assets/icon.svg` - Vector source
2. `assets/icon.png` - 512x512
3. `assets/icon-1024.png` - 1024x1024
4. `androidApp/src/main/res/mipmap-*/ic_launcher.png` - All densities
5. Update manifest if needed

## Prompt for AI
Use this with the design-taste-frontend skill:

"Design a premium app icon for 'Nocturne', a dark-themed local music player with iOS liquid glass aesthetics. Create an abstract symbol combining a musical note with a crescent moon shape. Use a deep dark background (#0f0f13) with a vibrant violet accent (#8b5cf6) that has a subtle inner glow. Keep it minimal, geometric, elegant. Must be recognizable at 48x48px. Output in SVG and PNG formats."

Start by using the design-taste-frontend skill to generate refined options, pick the best one, and export all sizes.
